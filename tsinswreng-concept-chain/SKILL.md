## 先看示例

假如你在寫一份關于減數分裂的教程, 按概念鏈的寫法寫起來是這樣:

```typst
///<概念鏈基礎設施>
//以項目實際情況爲準 
// set heading(numbering:) 只爲讓 @ 的默認引用渲染有東西可取
// （無編號標題的引用會報 cannot reference heading without numbering），
// 源碼直讀場景下編號樣式無意義。
#set heading(numbering: "1.")

#let MkTerm(display, descr) = {
	let Lbl = display.fields().at("label", default: none)
	if Lbl == none {
		panic("T 的第一個參數要寫成 [-<概念名>]：連字號後跟標籤")
	}
	[
		#heading(level: 2)[#str(Lbl)]
		#Lbl
		#descr
	]
}

// 前向引用包裝：編輯標記（「此條在後文才登記」），輸出原樣。
#let R(cont) = cont
///</概念鏈基礎設施>

///<正文>
以精子的形成爲例。
減數分裂開始之前,
精原細胞的每條 @染色體 先複製一次；
複製之後,
每條 @染色體 含有兩條姐妹 @染色單體 ,
兩條由 @着絲粒 連接在一起；

減數第一次分裂前期,
@同源染色體 兩兩配對,
這一現象叫 @聯會 ；
聯會後,
每對 @同源染色體 含有四條 @染色單體 ,
叫 @四分體 ；
這一時期,
非姐妹 @染色單體 之間常發生 @交叉互換 ,
相互交換一部分片段。

隨後,
紡錘絲牽引聯會的 @同源染色體 彼此分開,
分別進入兩個子細胞,
這是 @減數第一次分裂 ；
此時 @着絲粒 不分裂,
染色體數目就此減半。

進入 @減數第二次分裂 ,
兩個子細胞不再複製染色體,
@着絲粒 一分爲二,
姐妹 @染色單體 分開,
成爲兩條獨立的 @染色體 ,
細胞再分裂一次,
最終得到四個精細胞。
@減數分裂 的結果是,
成熟生殖細胞中的 @染色體 數目比原始生殖細胞的減少一半。
///</正文>


// 強烈建議按照先聲明後引用的順序,不要前向引用搞亂順序
// 引用已登記的條目直接寫 @名字（用得最多）
// 引用後文才登記的條目寫 #R[@名字]（不建議）
// @名字後須跟空格或標點（@會吞緊隨的漢字）
#let Terms = [
	//在Terms中爲MkTerm建立簡便寫法, 僅在該作用域內有效
	#let T = MkTerm
	
	// 寫法:
	// #T[-<詞條名>][
	// 	解釋
	// ]
	// <詞條名>前必須以-開頭, 否則typst會警告 「標籤未附屬」 從而不生效。
	// 標籤內的文字必須符合typst標籤語法規範, 不能有空格。在英文場景下可用下劃線代替空格
	#T[-<染色體>][
		染色體是細胞核內由 DNA 和蛋白質組成的結構,
		人有 23 對共 46 條。

	]

	#T[-<染色單體>][
		染色單體是 @染色體 複製的產物：
		複製之後,
		每條 @染色體 含有兩條染色單體,
		兩條互稱姐妹染色單體,
		由 @着絲粒 連接在一起。
	]

	#T[-<着絲粒>][
		着絲粒是 @染色體 上縊縮、
		連接兩條姐妹 @染色單體 的部位。
	]

	#T[-<同源染色體>][
		同源染色體是配對的兩條 @染色體 ：
		形狀和大小一般都相同,
		一條來自父方、一條來自母方。
		人體細胞中的 23 對 @染色體 ,
		每一對都是同源染色體。

		（減數分裂中他們如何兩兩配對,
		見 #R[@聯會] 。）
	]

	#T[-<聯會>][
		聯會指減數分裂過程中,
		@同源染色體 兩兩配對的現象。
	]

	#T[-<四分體>][
		四分體是 @聯會 後的結構：
		由於每條 @染色體 都含有兩條姐妹 @染色單體 ,
		聯會後的每對 @同源染色體 都含有四條 @染色單體 ,
		所以叫作四分體。
	]

	#T[-<交叉互換>][
		交叉互換指 @四分體 時期,
		非姐妹 @染色單體 之間發生交叉、
		相互交換一部分片段的現象。
	]

	#T[-<減數第一次分裂>][
		減數第一次分裂中,
		紡錘絲牽引聯會的 @同源染色體 彼此分開,
		分別進入兩個子細胞；
		此時 @着絲粒 不分裂,
		姐妹 @染色單體 仍然相連,
		染色體數目就此減半。
	]

	#T[-<減數第二次分裂>][
		減數第二次分裂緊隨 @減數第一次分裂 ,
		基本過程與有絲分裂相似：
		@着絲粒 一分爲二,
		姐妹 @染色單體 分開,
		成爲兩條獨立的 @染色體 ,
		細胞隨之分裂,
		產生四個精細胞。
	]

	#T[-<減數分裂>][
		減數分裂是進行有性生殖的生物,
		在產生成熟生殖細胞時進行的染色體數目減半的細胞分裂：
		減數分裂前 @染色體 複製一次,
		細胞連續分裂兩次,
		兩輪即 @減數第一次分裂 與 @減數第二次分裂 ；
		成熟的生殖細胞 @染色體 數目比原始生殖細胞的減少一半。
	]
]

#Terms
```

## 概念鏈

文章通常有兩部分組成: 正文+術語表。 有時也有可能沒有正文。

在**術語表**中, 要求術語的登記順序爲:

- 基礎概念在前、組合概念在後
- 每條只應當引用排在它前面的條目, **儘量避免引用未定義或後定義的條目**。 讀者從上往下走, 點任何一個引用, 跳到的條目裏儘量不應再出現沒講過的東西。 若實在繞不開, 需要引用後文纔聲明的條目, 則用`#R[@名字]`的寫法, 不用`@名字`的寫法
- 新概念插進鏈裏邏輯合適的位置, 不是無腦尾部追加

## 在已有文檔中新增概念條目的流程

分兩步:

1. 新增條目:
   - - 在 `Terms` 裏合適的位置插入。(未必叫`Terms`這個名字, 以項目實際爲準)
     - 自己找準位置, 不一定是在開頭或末尾, 位置順序要合邏輯
2. 替換引用:
   - 把原來的裸文字提及處都換成引用寫法。這一步要看仔細來 找準換準 不要漏

## 驗證

`typst compile` 可驗證

## 概念鏈的兩種使用場景

概念鏈有兩個場景, 第一個場景是直接寫typst, 不渲染成pdf或html等格式, 用戶直接在vscode裏看typst源碼, 用LSP插件來實現跳轉。

第二個場景就是渲染出來, 如pdf html等。

但當前的API設計已能覆蓋統一兩種不同場景, 即不管是甚麼場景, 調用方寫法都不變, 只有函數實現不同。

該skill中提供的示例是基于第一個場景的。 如果哪一天, 用戶想渲染出來 則只用改函數實現即可 調用方代碼一行不改。

本skill只主要提供一種思想及一種可能的最簡實現, 具體API寫法以項目實際爲準。
